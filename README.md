📥 Installation

Step 1

Clone Repository

git clone YOUR_REPOSITORY_LINK

Step 2

cd Milon-V3

Step 3

npm install

Step 4

Edit "config.json"

{
  "PREFIX": ".",

    "100081225144815"
  ]
}
